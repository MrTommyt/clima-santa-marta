# ADR-0002: Use monorepo

- **Status**: Accepted
- **Date**: 2026-07-05

## Context

This project is meant to contain different pieces and services by design, and since this is a showcase project, the idea to keep it all in a single repository makes the most sense.

## Decision

We will keep everything related to this project to this repository only

## Consequences

- Whenever revisiting something in the project everything should be on the same place.
- However, this will require extra steps when handling deployment.
